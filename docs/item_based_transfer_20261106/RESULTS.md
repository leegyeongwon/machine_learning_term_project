# 협업 정보 기반 전이 모델의 실험 결과 (2026-11-06)

## 실험 개요

영화 평점에서 얻은 협업 표현을 장르로 추정하고 이를 도서 평점 예측에 적용하는 실험을 수행하였다. 기존 Item-based CF는 해당 사용자가 이웃 아이템에 준 평점을 이용하지만, 새 모델은 영화 협업 표현 공간에서 선택한 이웃 영화들의 Train 평균 평점을 이용한다. 따라서 같은 책에는 모든 사용자에게 같은 점수를 반환하는 비개인화 전이 모델이다.

기존 코드를 보존한 별도 구현으로 영화 Train 17,401,383행과 Validation 2,175,173행 전체를 사용하였다. 영화 Validation에서 선택한 설정은 협업 표현 차원 수 rank=8, Ridge 규제 계수 alpha=100, 이웃 수 K=10이다. 이 설정을 고정한 뒤 기존 Goodbooks Test 597,648행을 평가하였다.

## 영화 Validation 및 도서 Test 결과

MAE와 RMSE는 값이 낮을수록 예측 오차가 작음을 뜻한다. 비교에 사용한 세 모델은 다음과 같다.

- `source_global_mean`은 모든 아이템에 영화 Train 전체 평균 평점을 예측한다.
- `raw_genre_cosine`은 장르 유사도로 이웃 영화를 선택하고 영화 Train 평균 평점을 가중평균한다.
- `cf_metric_distillation`은 장르에서 추정한 협업 표현으로 이웃 영화를 선택하고 영화 Train 평균 평점을 가중평균하는 새 모델이다.

| 모델 | 영화 Validation MAE | 영화 Validation RMSE | Goodbooks Test MAE | Goodbooks Test RMSE |
|---|---:|---:|---:|---:|
| 영화 Train 전체 평균 (`source_global_mean`) | 0.836722 | 1.055111 | 0.905561 | 1.049362 |
| 장르 KNN (`raw_genre_cosine`) | 0.886953 | 1.093479 | 1.036270 | 1.216714 |
| 협업 정보 기반 전이 (`cf_metric_distillation`) | 0.886334 | 1.089380 | 1.005357 | 1.177881 |

새 모델의 도서 오차는 장르 KNN보다 MAE 0.030913, RMSE 0.038832 낮았다. 반면 영화 Train 전체 평균보다 MAE 0.099796, RMSE 0.128520 높았다. 영화 Validation에서도 전체 평균 기준선보다 오차가 높았다. 따라서 장르 KNN 대비 개선은 나타났지만 단순 평균 기준선보다 우수한 모델이라는 결론은 내릴 수 없다. 도서 결과를 확인한 뒤 설정을 변경하거나 다시 선택하지 않았다.

## 협업 정보의 역할과 추가 진단

### 장르와 협업 표현의 학습 대응을 섞은 비교

협업 정보가 예측에 미치는 영향을 확인하기 위해 영화 장르와 협업 표현의 학습 대응만 섞은 teacher permutation 결과를 비교하였다. 실제 이웃 영화의 협업 표현과 평균 평점은 유지하였다.

| 영화 Validation 비교 | MAE | RMSE |
|---|---:|---:|
| 원래 대응으로 학습한 모델 | 0.886334 | 1.089380 |
| 학습 대응을 섞은 모델 | 0.911207 | 1.103712 |

대응을 섞었을 때 예측값의 평균 절대 변화는 0.181371이었다. 이는 장르와 협업 표현 사이에서 학습한 관계가 실제 예측에 영향을 준다는 결과이다. 다만 이 결과만으로 개인화가 가능하거나 도서 예측 성능이 우수하다고 판단할 수는 없다.

차원 수 rank-8로 정규화한 협업 표현의 유사도 복원 오차도 확인하였다. 표본 영화 쌍에서 자기 자신과의 유사도를 제외한 코사인 유사도의 재구성 MSE는 약 0.221440이었다. 이는 낮은 차원으로 요약하는 과정에서 원래 협업 정보의 일부가 손실됨을 보여준다.

### 학습에서 제외한 영화 아이템에 대한 진단

영화 Train에서 231개 아이템의 평점 904,256행을 제외하고 고정된 설정으로 해당 아이템을 예측하는 진단을 수행하였다. 도서 데이터는 사용하지 않았으며 이 결과로 설정을 조정하지 않았다.

| 모델 | 제외한 영화 아이템의 MAE | 제외한 영화 아이템의 RMSE |
|---|---:|---:|
| 협업 정보 기반 전이 | 0.891977 | 1.095705 |
| 장르 KNN | 0.883713 | 1.095634 |
| 영화 Train 전체 평균 | 0.854889 | 1.078341 |

이 진단에서도 새 모델은 장르 KNN이나 전체 평균 기준선보다 좋은 결과를 보이지 않았다. 영화 내부에서 수행한 진단이므로 새로운 도메인에 대한 성능을 보장하는 결과는 아니다.

### 도서 평점의 예측 경향

예측값과 설정을 고정하고 최종 평가를 마친 뒤 결과를 설명하기 위한 통계를 계산하였다.

| 항목 | 값 |
|---|---:|
| 실제 도서 Test 평균 평점 | 3.920607 |
| 협업 정보 기반 전이 모델의 예측 평균 | 3.322098 |
| 영화 Train 전체 평균 기준선의 예측 평균 | 3.570683 |
| 협업 정보 기반 전이 모델의 평균 부호 오차 | -0.598510 |

평균 부호 오차는 예측값에서 실제 평점을 뺀 값의 평균이다. 음수인 결과를 통해 새 모델이 도서 평점을 전반적으로 낮게 예측하는 경향을 확인하였다. 그 원인을 구분하는 실험은 수행하지 않았으며 이 통계로 파라미터를 변경하지 않았다.

## 영화 학습과 도서 평가의 분리

영화 Train으로 모델을 학습하고 영화 Validation으로 설정을 선택한 뒤 모델과 설정 파일의 해시를 기록하였다. 이후 도서 콘텐츠를 읽어 예측 배열, CSV, 책별 점수를 먼저 저장하고 SHA-256 해시를 기록하였다. 저장 파일이 변경되지 않았는지 확인한 다음 도서 Test 정답을 읽어 최종 평가를 수행하였다.

실행 중 도서 Train·Validation 평점 배열, 영화 Test, 미리 계산된 사용자 프로필, 줄거리·연도·수치 특징 배열은 데이터로 읽지 않았다. 파일 무결성을 확인하기 위한 전체 파일의 바이트 단위 해시 계산은 학습이나 평가에 배열을 사용하는 것과 구분한다.

도서 사용자 ID는 평가 행을 맞추는 데만 사용하였다. 영화와 도서의 숫자 ID가 같더라도 영화 사용자나 영화 아이템의 정보로 조회하지 않았다. 영화 장르 사전에 연결되는 장르가 없는 2,129권과 해당 도서의 Test 131,115행에는 영화 Train 전체 평균을 대체 예측값으로 사용하였다.

## 결과 파일과 실행 방법

모델 코드는 `src/item_based_transfer.py`와 `src/item_based_transfer_data.py`에 저장하였다. 실행기는 `scripts/run_item_based_strict_transfer.py`, 검증기는 `scripts/verify_item_based_strict_transfer.py`, 전용 테스트는 `tests/test_item_based_strict_transfer.py`이다. 관련 문서는 `docs/item_based_transfer_20261106/`에 정리하였다.

전체 결과 경로는 `results/item_based/strict_transfer_20261106_0007_full/`이다.

| 파일 | 저장 내용 |
|---|---|
| `source_model_frozen.npz` | 영화에서 학습한 모델을 저장하였다. |
| `selected_config.json` | 영화 Validation으로 선택한 설정을 저장하였다. |
| `book_test_predictions_frozen.csv/.npz` | 도서 Test 행별 예측값을 저장하였다. |
| `book_item_scores_frozen.csv` | 책별 예측 점수를 저장하였다. |

실행 로그, 예측 파일 해시 기록(seal), 배열 접근 기록(array_access), 독립 검증 결과와 전체 보고서도 같은 폴더에 저장하였다. 실행 명령은 다음과 같다.

```powershell
.venv\Scripts\python.exe -B scripts/run_item_based_strict_transfer.py --smoke
.venv\Scripts\python.exe -B scripts/run_item_based_strict_transfer.py
.venv\Scripts\python.exe -B scripts/verify_item_based_strict_transfer.py --run-dir results/item_based/strict_transfer_20261106_0007_full
```

로컬 복구 지점은 `local_recovery/item_based_20261105_234311_KST/`이다. 백업한 96개 파일의 원본·사본 SHA-256이 일치함을 확인하였다. 복구 방법은 `RESTORE.md`에 기록하였다. 기존 코드를 수정하지 않은 별도 구현이므로 기존 모델, 전처리 코드, 공유 NPZ에 되돌릴 변경은 없다.

## 결과의 해석과 한계

새 모델은 영화의 협업 정보를 도서 예측에 전달하지만 사용자별 도서 선호를 추정하는 모델은 아니다. 장르 정보만 사용하므로 같은 장르 조합의 아이템을 구별하기 어렵고, 협업 정보를 압축하고 추정하는 과정에서도 손실이 발생한다. 실험에서는 장르 KNN보다 도서 오차가 낮았지만 영화 Train 전체 평균 기준선을 넘지는 못하였다.

영화 Validation 결과만으로 도서 전이 성능을 보장할 수는 없다. 또한 기존 NPZ만으로는 앞선 데이터 선정 과정을 되돌릴 수 없다. 참고 논문과 본 구현의 차이, 학습 수식, 모델 사용 방법, 기존 Hybrid와의 비호환성은 `README.md`와 전체 `REPORT.md`에 정리하였다.
