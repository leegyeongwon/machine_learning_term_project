# 추천시스템 최종 실험 결과

## 프로젝트 개요

MovieLens 영화 평점으로 Item-based CF, Content-based, Hybrid 추천 모델을 구현하고, Goodbooks 도서 데이터에서도 같은 추천 방법을 적용할 수 있는지 평가하였다. 영화는 MovieLens 32M 중 TMDB 5000과 연결된 평점 21,751,729건을, 도서는 Goodbooks-10k 평점 5,976,479건을 사용하였다.

## 모델 구현

### Item-based CF

사용자들의 평점 패턴을 이용해 아이템 간 코사인 유사도를 계산한다. 예측할 아이템과 유사한 아이템 중 해당 사용자가 평가한 이웃을 선택한다. 이웃에 남긴 평점을 유사도로 가중평균하여 예측한다. 유효한 이웃이 없으면 사용자 평균, 아이템 평균, 전체 평균 순으로 대체값을 사용한다.

### Content-based

장르, 연도, 줄거리 임베딩과 사용자 선호 정보를 이용한다. 줄거리 임베딩은 영화 Train에 등장한 아이템으로 학습한 SVD 변환을 통해 1,024차원에서 32차원으로 줄인다. Ridge 회귀로 사용자 평균 평점에서의 잔차를 예측하고, 사용자 평균에 예측 잔차를 더해 최종 평점을 구한다. 도서에서도 영화에서 학습한 회귀 계수와 변환 기준은 유지한다.

### Hybrid

Item-based와 Content-based의 예측 평점을 가중합한다. 결합 비중은 영화 Validation 데이터에서 선택하였다. 최종 비중은 Item-based 85%, Content-based 15%이며 도서 평가에서도 같은 비중을 사용하였다.

## 실험 조건

| 항목 | 설정 |
|---|---|
| 영화 데이터 | MovieLens 32M + TMDB 5000 연결 데이터 |
| 도서 데이터 | Goodbooks-10k |
| Train / Validation / Test | 8:1:1 |
| Random seed | 42 |
| Item-based K | 50 |
| Ridge alpha | 100 |
| Hybrid Item 비중 | 0.85 |
| 평가 지표 | MAE, RMSE |

영화 Train으로 학습하고 Validation에서 K, Ridge alpha, Hybrid 비중을 선택하였다. K는 20·30·50, Ridge alpha는 1·10·100을 비교했으며, Hybrid Item 비중은 0~1을 0.01 간격으로 비교하였다. Validation MAE를 우선하고 동률이면 RMSE와 작은 후보값 순으로 선택하였다. 설정을 확정한 뒤 Test를 평가했으며, Test 결과로 재튜닝하거나 Train과 Validation을 합쳐 다시 학습하지 않았다.

2026-11-03 생성 전처리 데이터를 그대로 사용하였다. 도서 Train은 도서 평가에 필요한 사용자·아이템 정보를 만드는 데 사용하고, 도서 Validation은 설정 선택 없이 별도 진단에만 사용하였다.

## 실험 결과

MAE와 RMSE는 낮을수록 좋다. 표는 `final_metrics.csv`의 값을 소수점 여섯 자리로 표시한 것이다.

| 모델 | 영화 MAE | 영화 RMSE | 도서 MAE | 도서 RMSE |
|---|---:|---:|---:|---:|
| Item-based | 0.636516 | 0.857134 | 0.635693 | 0.862414 |
| Content-based | 0.714774 | 0.928031 | 0.746457 | 0.963775 |
| Hybrid | 0.633949 | 0.848977 | 0.636393 | 0.850337 |

영화에서는 Hybrid가 MAE와 RMSE 모두 가장 낮았다. 다만 Item-based와 비교한 개선 폭은 MAE 0.002567, RMSE 0.008156으로 작았다. 두 모델을 결합해 오차를 낮추기는 했지만, 단일 Item-based에 비해 큰 차이가 난 것은 아니다.

도서에서는 Item-based의 MAE가 가장 낮고 Hybrid의 RMSE가 가장 낮았다. Hybrid는 Item-based보다 RMSE가 0.012076 낮았지만 MAE는 0.000700 높았다. 같은 결합 비중을 사용해도 도메인과 지표에 따라 모델의 순위가 달라졌으므로, Hybrid가 언제나 가장 좋다고 보기는 어렵다.

Content-based는 두 도메인에서 다른 모델보다 오차가 높았다. 그러나 이번 비교만으로 특정 특징이나 모델 구조가 성능 차이의 원인이라고 단정할 수는 없다. 원인을 나누어 확인하는 추가 실험은 수행하지 않았다.

## 교차 도메인 평가의 한계

영화와 도서는 사용자와 아이템이 직접 연결되지 않는다. Item-based는 영화에서 선택한 K를 유지하지만, 책 간 유사도는 도서 Train 평점으로 새로 계산하였다. Content-based는 영화에서 학습한 계수와 변환 기준을 유지하면서 도서 Train으로 사용자 평균과 선호 프로필을 만들었다. Hybrid도 이 두 예측을 결합하므로 도서 평점을 사용한다.

따라서 이 실험은 영화 모델을 추가 정보 없이 도서에 적용한 Zero-shot 실험이 아니다. 같은 추천 방법과 일부 설정을 다른 도메인에 적용할 수 있는지 확인한 Support-adapted 평가이다. 영화와 도서는 평점 분포와 범위도 다르며, 영화는 0.5~5점, 도서는 1~5점이다. 도서 출판연도 이상값 10건도 보정하지 않았으므로, 두 도메인의 오차 차이를 순수한 전이 성능으로 해석하지 않는다.

## 결론

영화에서는 두 모델의 예측을 결합한 Hybrid가 가장 낮은 오차를 보였다. 도서에서는 MAE와 RMSE의 최저 모델이 달라, 결합 모델이 모든 지표에서 우수하지는 않았다. Book Train을 활용하는 조건에서 같은 추천 방법과 영화에서 선택한 설정을 도서에도 적용할 수 있음을 확인하였다. 다만 이를 영화 모델의 직접적인 Zero-shot 전이 결과로 설명해서는 안 된다.
